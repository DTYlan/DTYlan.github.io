DTYlan's TOD Calculator

Calculate TOD with adjustable Descent Path and Speed Constraints.

Tutorial

  1. Input your current altitude then your target altitude e.g. IAF.
  2. Target Descent Path is typically 3° on an A320, some aircraft with less drag e.g. A330 will use 2.5°.
  3. Input your indicated airspeed below FL280. (Only required if using a speed constraint)
  4. Constraints are setup for the default 250 knots below FL100. Clear the constraint fields if they are not needed.
  5. Calculate and begin descent according to the result. (Speed constraint will require you to level off)
